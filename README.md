# ChatGPT Work 无法访问本机浏览器：排查记录

> 记录时间：2026-11-22。本文只记录本次和此前排查中实际观察到的情况；不同 Work 会话可能连接到不同执行端。

## 遇到的问题

Mac 上已安装 ChatGPT 原生桌面版，ChatGPT 的电脑操控权限及 macOS 辅助功能权限也已开启，但部分 Work 会话无法访问本机浏览器或使用本机已登录的 Firefox。还有过 Work 发送按钮变灰、任务不能启动的情况。

仅凭桌面版安装位置、系统授权状态或任务曾读取本机文件，不能证明当前任务获得了 Mac 桌面和浏览器控制通道。

## 核心问题：为什么会卡住？

桌面版已安装、macOS 权限已开启，只能证明应用和权限条件存在，不能证明**当前 Work 会话**已经接上本机控制执行端。历史排查中，一些会话实际运行在 Linux/Chromium；另有一次本机 rendezvous WebSocket 超时。这说明故障可能卡在 Work 会话到本机控制通道的连接握手，而不一定是 Safari 本身或邮箱登录。

**为什么要查终端配置？**因为界面上的授权开关看不出连接在哪一层失败。只读检查执行端、代理、相关配置和连接日志，可以判断是会话跑在别的执行端，还是本机控制通道连接失败，再决定最小修复。终端检查是为了收集定位证据，不是盲目尝试命令。

本案例的本机代理 `127.0.0.1:12000` 和 rendezvous WebSocket 超时是实际记录到的排查线索；它们让连接/代理链路值得优先检查，但尚未证明是唯一根因。加入 `respect_system_proxy = true` 后曾有一次任务成功，却没有对照测试，**不能据此宣称该配置已证实修复问题**。发送按钮变灰的直接原因也仍待确认。

需要让其他 AI 一步步带你排查时，复制 [通用排障提示词](PROMPT.md)。它要求 AI 先识别操作系统和故障层级，再解释每一步检查目的，逐项收集证据；不会把 Mac 命令套到 Windows。

## 如何定位

### 1. 先核对当前会话的执行端

检查 Work 当前可见的操作目标和实际应用，而不是根据 ChatGPT 安装在哪台电脑推断：

- 本次检查中，电脑操控工具报告的目标为 `mac`；本机命令执行端报告为 Darwin / macOS。
- 当前可见的原生应用包括 Safari、Firefox、ChatGPT 和 GitHub Desktop。
- 另一次会话曾看到 Linux/XFCE 桌面和 Chromium。那只能说明那次会话的执行端是 Linux，不能代表本次或所有 Work 会话。

**判别要点：**当前会话能否看到并操作原生 macOS 应用，才是本机桌面控制通道的实测证据。单独看到文件或文件路径，只能说明文件可访问。

### 2. 实际检查 Safari 和 Firefox

- Safari：在原生 Safari 中打开 GitHub Desktop 官方页面，并操作页面上的 Release Notes 导航；地址栏随后显示官方发布说明页面。该操作验证了本次会话可以控制 Mac 上的 Safari。
- Firefox：在原生 Firefox 中读取 GitHub 页面，页面显示已登录账号 `jiahuishe0204`；当前会话能够访问该浏览器及其现有登录状态。
- 因此，本次 Work 会话的 Mac 桌面操控及 Safari / Firefox 浏览器操作均已实测通过。该结果只证明本次会话，不自动证明其他会话也连到 Mac。

### 3. 记录未确认的启动原因

- 历史诊断记录中，Work 曾在连接本地执行端时出现 rendezvous WebSocket timeout。它是一次观察到的连接错误，尚未证明它就是发送按钮变灰或其他启动失败的直接原因。
- 发送按钮变灰的具体触发条件仍未确认；目前没有足够证据下结论。
- 曾备份并修改 `~/.codex/config.toml`，加入 `respect_system_proxy = true`，随后重启 ChatGPT。之后有 Work 任务成功运行，但没有对照测试隔离该配置的影响。**因果未证实**，不能把它写成已确认根因或解决方案。

## 采取了什么措施

1. 逐个 Work 会话核对执行端，避免把“Mac 上安装了桌面版”误当成“当前任务已接入 Mac”。
2. 选择已确认能看到原生 macOS 应用的 Work 会话，并在该会话里直接操作 Safari、Firefox，确认浏览器控制能力。
3. GitHub Desktop 本次可见为正在运行，但读取其窗口时连续超时；于是改用本机已登录的 Firefox 继续 GitHub 操作，没有使用云端 Chromium，也没有在聊天中输入密码或验证码。
